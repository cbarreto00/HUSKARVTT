# g11
Repositório do Grupo 11 da disciplina de Programação Orientada a Objetos

RPG Virtual

Plataforma VTT que visa a criação de mesas de RPG com interação virtual entre usuários, abordando diferentes ferramentas para uso ao decorrer da experiência dos jogadores. Baseado nos livros, dados e formatos do famoso RPG Dungeons & Dragons. Com objetivo de superar e inovar a plataforma já existente Roll20, que apesar de possuir uma ótima perspectiva, é alvo de diversas deficiências notadas pelos usuários, essas que só são otimizadas na sua versão paga, o nosso projeto de RPG Virtual aborda a democratização através de um uso de qualidade e totalmente gratuito.
De início, o projeto terá sua interface gráfica em desktop, com planejamento de futuramente ser multiplataforma (mobile, web)
